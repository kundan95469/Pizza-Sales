# 🍕 Pizza Sales Analysis Dashboard

## 📊 Project Overview

The **Pizza Sales Analysis Dashboard** is an interactive Power BI dashboard designed to analyze pizza sales performance and identify important business trends.

The dashboard provides insights into **total orders, pizzas sold, revenue, average pizzas per order, average order value, sales trends, pizza categories, pizza sizes, and best/worst-selling pizzas**.

The project helps understand customer ordering patterns and identify which pizza products contribute the most and least to overall business performance.

---

## 🎯 Project Objectives

* Analyze overall pizza sales performance.
* Track total orders, pizzas sold, and revenue.
* Identify the busiest days and months.
* Analyze daily and monthly order trends.
* Compare sales across pizza categories and sizes.
* Identify the **Top 5 best-selling pizzas**.
* Identify the **Bottom 5 worst-selling pizzas**.
* Analyze pizzas based on revenue, quantity, and number of orders.
* Create an interactive dashboard using Power BI.

---

# 📌 Dashboard Features

## 1️⃣ Overall Sales Analysis

The main dashboard provides important KPIs for monitoring pizza sales performance.

### Key KPIs

* 🍕 **Total Orders:** 21K
* 🍕 **Total Pizzas Sold:** 50K
* 💰 **Total Revenue:** 817.86K
* 📦 **Average Pizzas per Order:** 2.32
* 💵 **Average Order Value:** 38.31

These KPIs provide a quick overview of the overall business performance.

---

## 2️⃣ Busiest Days & Time Analysis

The dashboard analyzes order patterns based on days and months.

### Day-wise Analysis

The dashboard shows that orders are higher during:

* **Friday**
* **Saturday**

Friday records the highest daily order volume in the displayed analysis.

### Monthly Analysis

The dashboard provides monthly order trends from **January to December**.

The monthly trend helps identify periods with higher and lower order volumes.

---

## 3️⃣ Pizza Category Analysis

The dashboard analyzes sales contribution across different pizza categories.

### Categories

* Classic
* Supreme
* Chicken
* Veggie

A donut chart is used to visualize the percentage contribution of each pizza category to overall sales.

The dashboard highlights that the **Classic category contributes the highest share of sales and total orders**.

---

## 4️⃣ Pizza Size Analysis

The dashboard analyzes sales based on pizza size.

### Pizza Sizes

* Large
* Medium
* Regular
* X-Large
* XX-Large

The analysis shows that **Large-size pizzas contribute the highest share of sales**.
